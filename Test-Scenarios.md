# Test Scenarios – E-commerce Website

**Project:** E-commerce Website Manual Testing

**Application Under Test:** https://www.saucedemo.com/

## 1. Login Module
- TS_LOGIN_001: Verify login with valid credentials.
- TS_LOGIN_002: Verify login with an invalid username.
- TS_LOGIN_003: Verify login with an invalid password.
- TS_LOGIN_004: Verify login with empty username and password.
- TS_LOGIN_005: Verify logout functionality.

## 2. Product Module
- TS_PRODUCT_001: Verify that products are displayed after login.
- TS_PRODUCT_002: Verify product sorting functionality.
- TS_PRODUCT_003: Verify product details are displayed correctly.

## 3. Shopping Cart Module
- TS_CART_001: Verify that a product can be added to the cart.
- TS_CART_002: Verify that a product can be removed from the cart.
- TS_CART_003: Verify that the cart displays the correct product.

## 4. Checkout Module
- TS_CHECKOUT_001: Verify checkout with valid customer details.
- TS_CHECKOUT_002: Verify checkout with missing required information.
- TS_CHECKOUT_003: Verify the order summary before completion.
- TS_CHECKOUT_004: Verify successful order completion.
