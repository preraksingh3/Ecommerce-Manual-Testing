# E-commerce Website Manual Testing Project

## Project Overview
This project focuses on manually testing an e-commerce website to verify that its main features work as expected.

## Objective
To identify defects, validate application functionality, and ensure a smooth user experience through manual testing.

## Application Under Test
- **Website:** https://www.saucedemo.com/
- **Testing Type:** Manual Testing
- **Testing Approach:** Black-box testing

## Scope of Testing
- Login and Logout
- Product Listing and Product Sorting
- Add to Cart and Remove from Cart
- Checkout Process
- Input Validation and Error Messages

## Types of Testing
- Functional Testing
- Positive Testing
- Negative Testing
- Smoke Testing
- Regression Testing

## Project Deliverables
- Test Scenarios
- Test Cases
- Bug Reports
- Test Execution Report
- Screenshots of Actual Defects, if found

## Test Environment
- **Browser:** Google Chrome
- **Operating System:** Windows 11
- **Testing Method:** Manual
